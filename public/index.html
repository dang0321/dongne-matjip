자주 찾는 동네

    네이버 검색 API 키를 연결하세요

    식당과 블로그 리뷰를 네이버 검색 API로 찾아옵니다. 키를 한 번만 등록하면 됩니다.

    1. 네이버 클라우드 플랫폼 콘솔에 로그인합니다. 처음이라면 회원가입이 필요합니다.
    2. Services에서 Application Services 아래의 NAVER API HUB를 열고, Application 메뉴에서 ‘Application 등록’을 누릅니다. API 카드 가운데 ‘블로그’와 ‘지역’ 두 개를 체크하고, 영문 이름을 붙여 만듭니다.
    3. 만든 Application의 ‘인증 정보’에서 Client ID와 Client Secret을 복사해 아래에 붙여 넣습니다.

    예전에 네이버 개발자센터에서 받은 검색 API 키가 있다면 그대로 넣어도 됩니다. 어느 쪽 키인지는 자동으로 알아냅니다. 개발자센터 키는 2027년 6월 30일까지만 쓸 수 있습니다.

    키는 이 컴퓨터의 .env 파일에만 저장됩니다.

    이렇게 순위를 매깁니다

    1. 고른 지역의 식당을 음식 종류별로 검색해 후보를 모읍니다.
    2. 후보마다 블로그 리뷰를 30개까지 읽고, ‘내돈내산’ 글과 ‘제공받아’ 쓴 글이 각각 얼마나 되는지 셉니다.
    3. 리뷰의 양, 내돈내산 비율, 글의 표현, 최근 반응으로 점수를 매겨 높은 순으로 보여 줍니다.

      점수는 블로그 글의 양과 표현으로 계산한 참고용 숫자입니다. 영업시간과 휴무일은 지도에서 확인하세요.
