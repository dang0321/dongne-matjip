# 동네 맛집 순위

지역을 고르면 네이버 검색으로 식당 후보를 모으고, 식당마다 블로그 리뷰를 읽어 점수순 추천 목록을 만들어 주는 프로그램입니다. 내 컴퓨터에서 실행하고 브라우저로 봅니다.

- 리뷰가 많은 곳보다 **"내돈내산" 글이 많은 곳**을 높게 칩니다. "제공받아" 쓴 글의 비중이 크면 경고를 붙입니다.
- Node.js 20 이상만 있으면 되고, 실행하는 데 설치할 패키지는 없습니다.
- 네이버 검색 API 키는 **각자 본인 것을 발급받아** 씁니다. 무료입니다(한시적 무료, 2026년 11월 기준).

## 쓰기 전에 꼭 읽어 주세요

이 프로그램은 네이버 검색 API를 씁니다. [NAVER API 서비스 이용약관](https://www.ncloud.com/product/applicationService/NAVERAPIHUB)을 지키는 것은 키를 발급받은 사용자 본인의 책임입니다. 약관을 어기면 키가 정지될 수 있습니다.

- **본인이 발급받은 키를 본인 컴퓨터에서만 쓰세요.** 키를 남에게 주거나 남의 키를 쓰면 안 됩니다(약관 7.2 ②).
- **웹사이트로 올려 여러 사람에게 서비스하지 마세요.** 검색 결과를 제3자에게 다시 제공하는 것(7.3 ⑥), 한 서비스에서 여러 사람의 키를 쓰는 것(7.3 ⑤)이 금지되어 있습니다.
- **검색 결과를 따로 저장하거나 다른 곳에 옮겨 싣지 마세요.** 결과의 복제·저장·가공·배포가 제한됩니다(7.3 ③). 이 프로그램은 결과를 디스크에 저장하지 않고, 켜져 있는 동안 메모리에 10분만 둡니다.
- **광고를 붙이지 마세요**(7.3 ④).

이 프로그램은 검색 결과에 자체 점수를 매겨 순서를 바꿔 보여 줍니다. 약관의 검색 API 특약 2.1은 검색결과를 "독립적으로 노출"하고 왜곡하지 말라고 정하고 있어, 혼자 보는 용도라도 이 부분이 약관에 완전히 맞는다고 장담할 수 없습니다. 걱정되면 네이버에 문의한 뒤 쓰세요.

## 네이버 검색 API 키 받기

2026년 7월 31일부터 네이버 개발자센터에서는 검색 API 키를 새로 받을 수 없고, 네이버 클라우드 플랫폼의 **NAVER API HUB**에서 받아야 합니다.

1. [네이버 클라우드 플랫폼 콘솔](https://console.ncloud.com/)에 로그인합니다. 처음이라면 회원가입이 필요합니다.
2. Services > Application Services > NAVER API HUB > Application에서 "Application 등록"을 누릅니다. API 카드 가운데 **"블로그"**와 **"지역"** 두 개(초록색 "NAVER 검색" 표시)를 체크하고, 이름(영문·숫자·하이픈, 20자 이내)을 붙여 만듭니다. "검색"이라는 이름의 API는 따로 없습니다.
3. 만든 Application의 "인증 정보"에서 Client ID와 Client Secret을 복사해 프로그램 화면에 붙여 넣고 "키 저장"을 누릅니다.

키는 이 폴더의 `.env` 파일에만 저장됩니다. `.env`는 `.gitignore`에 들어 있어 저장소에 올라가지 않습니다.

예전에 개발자센터에서 받은 키도 2027년 6월 30일까지는 쓸 수 있습니다. 어느 쪽 키인지는 저장할 때 자동으로 알아냅니다.

검색 한 번에 API를 최대 110회쯤 부릅니다. 하루 한도가 25,000회라 하루 200번 넘게 검색할 수 있습니다.

## 순위를 매기는 방법

1. `지역 + 음식 종류` 검색어 여러 개로 지역 검색을 해서 후보를 모읍니다(검색어마다 정확도순 5곳, 리뷰 많은 순 5곳).
2. 후보 최대 30곳마다 블로그 검색을 세 번 합니다.
   - `지역 + 식당 이름`: 글 30개의 제목·요약과 전체 글 수
   - `지역 + 식당 이름 + 제공받아`: 협찬·체험단 글 수
   - `지역 + 식당 이름 + 내돈내산`: 자기 돈으로 먹고 쓴 글 수
3. 아래 신호를 합쳐 0~100점을 매깁니다. 가중치는 `public/lib/scoring.js`의 `WEIGHTS`에서 바꿀 수 있습니다.

| 신호 | 비중 | 뜻 |
| --- | --- | --- |
| 리뷰량 | 27% | 제공받아 쓴 글을 뺀 블로그 글 수. 같은 검색에서 가장 많은 식당에 견준 값 |
| 내돈내산 | 20% | 내돈내산 글 수 ÷ (내돈내산 + 제공받아 글 수) |
| 글의 표현 | 18% | "맛있", "재방문" 같은 긍정 표현과 "별로였", "불친절" 같은 부정 표현의 비율 |
| 최근 반응 | 15% | 읽은 글이 얼마나 최근 것인가 |
| 동네 인기 | 15% | 지역 검색에 얼마나 자주, 높은 순위로 나왔는가 |
| 글쓴이 다양성 | 5% | 한 사람이 여러 번 쓴 글이 섞여 있지 않은가 |

제공받아 쓴 글이 전체의 20%를 넘으면 "제공받아 쓴 글 N%" 경고가 붙습니다.

알아 둘 점:

- 글 수는 네이버 검색이 알려 주는 어림값입니다. "전라도식당"처럼 흔한 이름은 다른 가게 글이 섞여 실제보다 많게 나올 수 있습니다.
- 긍정·부정은 제목과 요약에 나온 낱말로만 판단합니다. 본문 전체를 읽는 것이 아닙니다.
- 지역 검색이 한 번에 5곳만 주기 때문에, 후보는 한 지역에 수십 곳 정도입니다. 그 동네의 모든 식당을 훑는 것이 아닙니다.

점수는 참고용입니다.

## 개발

```bash
node --test
```

```bash
node dev/preview.js
```

`dev/preview.js`는 가짜 네이버 서버(`dev/mock-naver.js`)에 연결한 미리보기를 http://localhost:3211 에 띄웁니다. 키 없이 화면을 확인할 때 씁니다. 여기 나오는 식당과 리뷰는 모두 지어낸 것입니다.

## 실행 파일(exe) 만들기

Node 없이 더블클릭으로 켜지는 파일을 만듭니다. 빌드한 운영체제용 파일 하나가 `dist/`에 나옵니다(약 94MB).

```bash
npm install
```

```bash
npm run build:exe
```

- 실행하면 브라우저가 열리고, 네이버 키는 사용자 폴더(`%APPDATA%\dongne-matjip\.env`)에 저장됩니다. exe를 남에게 건네도 키는 따라가지 않습니다.
- **서명이 없는 파일입니다.** Windows 11의 "스마트 앱 컨트롤"이 켜진 PC에서는 실행이 아예 차단되고, 꺼진 PC에서는 "PC 보호" 경고가 뜹니다.

## 구조

- `server.js`: 실행 시작점
- `src/app.js`: 로컬 서버(화면 파일 제공, 키 저장)
- `src/core.js`: API 본체(후보 모으기, 리뷰 가져오기)
- `src/recommend.js`: 네이버에서 후보와 리뷰를 가져오는 순서
- `src/naver.js`: 네이버 검색 API 호출(속도 제한, 재시도, 두 창구 지원)
- `src/regions.js`: 시/도와 시/군/구 목록, 음식 종류별 검색어
- `public/`: 화면
- `public/lib/`: 리뷰 분석과 점수 계산(브라우저에서 실행)
- `public/icons.js`: 음식 종류 아이콘
- `build/`: 실행 파일 빌드 스크립트
- `dev/`, `test/`: 가짜 네이버 서버와 테스트
